# 조합 트랙 결정 보류

- **태그 / 매트릭스 자산 위치** — `composition/` 안 vs 추천 트랙의 `champion-mapping`과 통합 폴더(예: `doc/champion-data/`).
- **앱 번들 vs 서버 fetch** — 번들이 단순. 서버는 패치 즉시 반영 가능. 일단 번들 시작.
- **시너지 규칙 가중치** — 1차는 모두 동등. 패치별 메타 동적 조정은 v2.
- **카운터 매트릭스 1차 범위** — 인기 챔피언 몇 명부터? 30 / 50 / 전체.
- **챔피언 검색 UX** — 검색창 vs 그리드 vs 즐겨찾기.
- **결과 신뢰도 표기** — "제안일 뿐" 명시 필요. 강한 UI 가이드.
