# 결정 보류 (메타 / 공용)

전체 프로젝트 차원의 미정 항목. 트랙별 결정은 각 폴더의 `pending.md` 참조.

- **자동 인식형(이미지 매칭) 도입 여부** — Android MVP 사용 후 재평가. iOS 트랙은 시작부터 매칭 기반이라 별개 문제.
- **챔피언별 정확한 궁 쿨다운 DB** — 양 트랙 모두 필요. 챔피언 선택 UI 도입 시 함께 추가.
- **다국어** — 1차는 한국어 단일. 영어는 패키지명/스토어 메타데이터에만.
- **트랙 간 공유 자산의 코드 레벨 공유 방식** — 한국 챔피언명 사전, 스펠 enum 등을 어떻게 둘 것인가.
