# 티어표 화면

라인별 추천(카드 5개)과 별개로, **전체 라인 챔피언 티어표**를 한 표에.

## 가치 제안
"지금 픽할 챔피언"(추천 카드)이 아닌 "전체 메타 흐름" 한눈에. lolm.qq.com 중국 페이지의 표를 한국어로 옮긴 형태.

## 화면 구성
- 라인 탭 (상단/정글/중원/하단/서포터 + 전체)
- 표 행: 순위 · 챔피언 아이콘 · 한글명 · 승률 / 픽률 / 밴율
- 정렬 가능 (기본: 승률 내림차순)
- 작은 폰트로 폰 폭 안에 맞춤. 가로 스크롤 회피.

## 데이터
[server](server.md) `/v1/tier` 전체 응답 한 번에 요청. 캐시는 [android-client](android-client.md)와 공유.

## 진입
오버레이 모드 전환 또는 `MainActivity` 버튼. 자세히는 [android-client](android-client.md).
