# MVP 기능 범위

## 슬롯 구성
적 챔피언 슬롯 5개 (P1~P5). 각 슬롯에 버튼 2개:
- 스펠 1 (기본: 점멸 150s)
- 스펠 2 (기본: 점화 90s)

궁극기 추적은 v0.1.0 범위에서 제외. v2 이후 재검토.

## 버튼 동작
- **탭**: 쿨다운 시작. 재탭 시 취소.
- **롱프레스**: 스펠 종류 순환 — 점멸 → 점화 → 회복 → 유체 → 탈진 → 방어 → 강타.

## 시각 상태 4단계
대기 / 카운트다운 / 임박(≤10s, 깜빡) / 완료(자동 대기 복귀).

## 본체
- 좌측 손잡이(`≡`) 드래그로 이동, 더블탭으로 접기.
- 포그라운드 서비스 + 알림으로 백그라운드 유지.

## 입력 방식 우선순위
실기 검증 결과 화면 가림 + 수동 탭 정밀도 부족 → [auto-chat-detect](auto-chat-detect.md) 자동 입력이 주력. 수동 탭은 폴백.
