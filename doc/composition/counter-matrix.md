# 카운터 매트릭스 (큐레이션 자산)

"적 챔피언이 X면 누구를 픽하면 좋은가" 표.

## 형식
챔피언 ID 기반 JSON:
```json
{
  "10001": {
    "counters": [10063, 10010, 10042],
    "note": "기동성으로 무빙. 사일런스를 흘리기."
  }
}
```

- `counters`: 추천 챔피언 ID 3~5개, 중요도 순.
- `note`: 한 줄 한국어 메모 (선택).

## 출처
사람 큐레이션. 1차는 인기 챔피언 30~50명, 나머지는 점진 보강.

## 정확도 한계
"제안" 수준. 룬/아이템/실력에 좌우 → 절대답 아님을 UI에 명시.
