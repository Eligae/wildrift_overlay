# 플랫폼 결정

## 공식 API 부재
와일드리프트는 PC LoL과 달리 **Live Client API가 없다**. 게임 상태 자동 인식의 합법적 경로 없음. → 사용자 수동 입력 + (옵션) 스크린샷 이미지 매칭만 가능.

## Android
시스템 오버레이 가능. `SYSTEM_ALERT_WINDOW` + `TYPE_APPLICATION_OVERLAY`. → **인게임 실시간 트래커** 트랙으로 전개.

## iOS
다른 앱 위 오버레이가 OS·앱스토어 양쪽에서 막혀 있음. → "인게임 오버레이" 포기. 대신 **로딩화면 스크린샷을 사용자가 공유 → 챔피언/스펠 인식**이라는 다른 가치 제안으로 트랙 분리.

두 트랙은 스펠 CD 표·챔피언 DB 같은 정적 데이터 자산만 공유.
