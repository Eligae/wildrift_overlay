# 게임 업데이트 인앱 알림

`https://wildrift.leagueoflegends.com/ko-kr/news/game-updates/` 신규 게시물을 **앱 진입 시점에만** 표시. 백그라운드 푸시 없음.

## 동작
1. `MainActivity.onResume`에서 마지막 본 글의 URL/timestamp를 prefs에서 로드.
2. 페이지 fetch → 최신 글 메타(제목, URL, 날짜) 파싱.
3. 마지막 본 URL과 다르면 **상단 배너** 노출: "🔔 새 업데이트: {제목}" → 탭 시 `CustomTabs`로 원문.
4. 사용자가 배너를 닫거나 글을 열면 그 URL을 prefs에 저장 → 다음 진입부터는 침묵.

## 데이터 소스
공식 페이지가 SPA일 경우 `og:` 메타 또는 임베디드 JSON 파싱 (DOM 셀렉터는 변동 가능, 폴백 로직 필요). 서버 측 프록시도 고려.

## 결정 보류
- **파싱 위치**: 클라이언트 직접 vs 서버 프록시(차단/캐시 유리).
- **다중 신규**: 여러 글 누적 시 "N개 새 글" 카운터 or 최신 1건만?
- **다국어**: ko-kr 고정. 영어 메인은 별도 트랙.

세부 액션은 하위 [news/](news/) 폴더로 분리 예정.
