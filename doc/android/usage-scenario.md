# 사용 시나리오 (한 라운드)

1. 메인 화면에서 오버레이 크기 슬라이더로 적정 크기 선택.
2. "오버레이 시작" → 화면 한쪽에 오버레이 떠 있음 (손잡이 드래그로 이동).
3. 챔피언 선택 단계에서 각 라인(TOP/JUG/MID/ADC/SUP)별 적 스펠을 롱프레스로 맞춤.
4. 인게임 — 적 미드 점멸 본 순간 MID 슬롯의 점멸 버튼 탭 → 150s 카운트다운.
5. 10s 이하 → 깜빡임. 0s → 자동 대기 복귀.
6. 오탭은 같은 버튼 재탭으로 취소.
7. 손잡이 단일 탭으로 토글: 전체 → 라인 라벨 숨김 → 완전 접힘.
