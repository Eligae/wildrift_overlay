# v0.1.0 — MVP

Android 인게임 오버레이. 적 5명의 스펠 쿨다운 수동 트래커.

## 기능
- 슬롯 5개 (TOP/JUG/MID/ADC/SUP), 각 F(점멸 150s) / I(점화 90s).
- 탭: 카운트다운 시작·취소.
- 롱프레스: 스펠 순환 (F→I→H→G→E→B→S).
- 시각 4단계: 대기 / 카운트다운 / 임박(≤10s 깜빡) / 자동 복귀.
- 손잡이 단일 탭 3단계: `−` → `≡` → `+`. 드래그 이동.
- 크기 슬라이더 0.5x~1.5x.
- 자동 저장: 위치/접힘/슬롯 상태/크기.
