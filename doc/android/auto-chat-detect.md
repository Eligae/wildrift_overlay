# 자동 채팅 감지 (옵트인)

와일드리프트는 적 챔피언이 소환사 주문을 사용하면 채팅창에 **정형 시스템 메시지**를 뿌린다. 이걸 캡처해 해당 슬롯의 카운트다운을 자동 시작.

## 동작
- 설정 토글 ON일 때만 활성. **기본 OFF**.
- 트리거: 게임이 자동 송출하는 시스템 메시지 (수동 채팅 아님).
- 인식 실패해도 수동 탭은 그대로 — 보조 기능.

## 매칭
- 형식이 일정 → 정규식 한 줄로 충분. fuzzy 불필요.
- 1차: **한국어 클라이언트**. 타 언어 패턴은 v2 이후.
- 챔피언명 + 스펠명 추출 → 슬롯 매핑. 5초 디바운싱.
- **선행 작업**: 실기에서 메시지 샘플 5~10개 수집 → 패턴 확정.

## 기술 옵션 (보류 → [pending](pending.md))
- **A. AccessibilityService** — 채팅이 SurfaceView/OpenGL이면 노드 트리에 텍스트가 없음.
- **B. MediaProjection + OCR(ML Kit)** — 채팅 ROI만 캡처. 정형이라 정확도 요구 낮음. ToS 정책 갱신 필요 ([`../tos.md`](../tos.md)).
