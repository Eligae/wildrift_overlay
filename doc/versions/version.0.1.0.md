# v0.1.0 — MVP

Android 인게임 오버레이. 적 5명의 스펠/궁 쿨다운 수동 트래커.

## 기능
- 슬롯 5개, 각 F(점멸 150s) / I(점화 90s) / R(궁 60s 프리셋 5종).
- 탭: 카운트다운 시작·취소.
- 롱프레스 F/I: 스펠 순환 (F→I→H→G→E→B→S).
- 롱프레스 R: 60→75→90→105→120 순환.
- 시각 4단계: 대기 / 카운트다운 / 임박(≤10s 깜빡) / 자동 복귀.
- 손잡이 ≡: 드래그 이동, 더블탭 접기.
- 자동 저장: 위치·접힘·슬롯 상태.

## 시스템
minSdk 26 / targetSdk 35. 포그라운드 서비스(specialUse) + 알림. 오버레이 외 터치는 게임으로 통과.
