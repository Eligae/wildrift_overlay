# 시너지 규칙 엔진

우리 팀 4명의 [태그](champion-tags.md)를 보고 부족한 역할 추론 → 그 역할에 맞는 챔피언 후보 N명 출력.

## 규칙 (1차)
1. **탱커 부재**: class에 `tank`/`fighter` 없으면 탱커.
2. **하드 CC 부재**: cc=`hard` 보유 없으면 CC.
3. **원거리 부재**: range=`ranged` 캐리 없으면 마크스맨/메이지.
4. **데미지 편중**: AD 4 또는 AP 4면 부족한 쪽.
5. **이니시 부재**: roles에 `engage` 없으면 이니시.

## 출력
규칙별 가중치 합 → 상위 3~5명. 각 추천에 "왜"(예: "탱커가 없습니다") 한 줄.
