# 자동 채팅 감지 (주력)

와일드리프트는 적이 스펠을 사용하면 채팅창에 **정형 시스템 메시지**를 뿌린다. 이걸 캡처해 슬롯 카운트다운을 자동 시작.

## 우선순위
실기 검증 결과 수동 탭은 게임 가림 + 정밀 터치 어려움 → **자동 입력이 주력**으로 격상. 수동 탭은 폴백.

## 동작
- 트리거: 게임 자동 시스템 메시지 (수동 채팅 아님).
- 감지 실패 시에만 수동 탭으로 보완.

## 매칭
- 정형 → 정규식 한 줄. 1차 한국어 클라이언트.
- 챔피언명 + 스펠명 추출 → 슬롯 매핑. 5초 디바운싱.
- **선행**: 실기에서 메시지 샘플 5~10개 수집 → 패턴 확정.
