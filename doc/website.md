# GitHub Pages 소개 페이지

프로젝트 공개 소개 페이지. 한국어 1차, 짧고 직설적.

## 구성 요소
1. **헤더**: 앱 이름 + 한 줄 소개.
2. **스크린샷 / 짧은 GIF**: 인게임 위 오버레이 모습.
3. **다운로드**: 최신 GitHub Release APK 직접 링크.
4. **사용법**: 설치 → 권한 부여 → 사용 시나리오 3~4컷.
5. **FAQ**: ToS / 안티치트 안전성, Play Store 부재 이유.
6. **링크**: 저장소, 이슈 트래커.

## 빌드
정적 HTML 한 장으로 시작. Jekyll/Hugo 등 정적 사이트 생성기 도입 안 함 — 페이지 한 장이라 과잉.

## 위치
저장소 루트의 `docs/` 디렉토리에서 GitHub Pages 활성. 기획 문서(`doc/`, 단수)와 헷갈리지 않게 구분.

## 다국어
영문은 v2 이후.
