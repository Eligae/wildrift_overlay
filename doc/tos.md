# ToS / 안전성

## 기본 (Default) — 하지 않는다
- 메모리 후킹
- 패킷 스니핑
- 자동 화면 캡처 / 입력 자동화

## 사용자가 OPT-IN 가능한 항목 (기본 OFF)
- **채팅 영역 부분 OCR** — 자동 채팅 감지 활성화 시. 채팅 ROI만 캡처하고 다른 영역·메모리·네트워크에는 접근하지 않음. [android/auto-chat-detect](android/auto-chat-detect.md) 참조.

## 원칙
- 게임 상태는 기본 100% 사용자 입력 기반.
- 안티치트(Vanguard 등) 환경에서도 단순 "화면 위 그림판" 수준.
- WR 공식 클라이언트 API 부재 — 사용자 입력과 OPT-IN 캡처 외에는 손대지 않는다.
