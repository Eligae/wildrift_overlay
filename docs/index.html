와일드리프트 인게임 중 적 챔피언의 스펠과 궁극기 쿨다운을 화면 위 오버레이로 추적. 한국어 티어표까지 한 앱에서.

APK 다운로드 v0.1.0 · 최신 Release
§ 01

주요 기능

  • 인게임 오버레이 — 적 5명 슬롯, 스펠 2개 (점멸/점화 등). 탭 한 번으로 쿨다운 시작.
  • 3단계 토글 — 손잡이 단일 탭으로 전체 / 라인 라벨 숨김 / 완전 접힘 순환.
  • 크기 슬라이더 — 0.5x ~ 1.5x. 폰/사용자 시야에 맞춰 조정.
  • 한국어 티어표 — 라인별 추천 카드 + 전체 표. lolm.qq.com 데이터 한국어화.
  • 자동 채팅 감지 (개발 중) — 적이 스펠 쓰면 채팅 메시지를 OCR로 잡아 자동 카운트다운.
§ 02

사용법

1

설치

APK 다운로드 후 폰에서 "출처 미상의 앱" 허용. Play Store 미배포.

2

권한 부여

앱에서 "오버레이 권한 부여" → 시스템 설정에서 다른 앱 위에 표시 ON.

3

오버레이 시작

"오버레이 시작" 버튼 → 좌상단에 슬롯 5개 표시. 손잡이 드래그로 위치 조정.

4

인게임

와일드리프트 실행 → 적 스펠 본 순간 해당 슬롯 탭. 카운트다운 시작.

§ 03

안전성 (FAQ)

메모리 후킹이나 패킷 스니핑을 합니까?
아니요. 게임 상태는 100% 사용자 수동 입력 기반. 메모리/패킷에 손대지 않습니다.
안티치트(Vanguard)에 안전한가요?
단순 "화면 위 그림판" 수준의 오버레이라 안전합니다. 게임 프로세스에 접근하지 않습니다.
왜 Play Store에 없나요?
귀찮아서요
자동 채팅 감지는 어떻게 동작하나요?
기본 OFF. 사용자가 토글로 켜면 채팅 영역만 OCR로 분석합니다. 다른 영역·메모리·네트워크엔 접근하지 않습니다.
