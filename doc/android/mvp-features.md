# MVP 기능 범위

## 슬롯
적 5명 (TOP/JUG/MID/ADC/SUP). 각 슬롯에 버튼 2개:
- 스펠 1 (점멸 150s)
- 스펠 2 (점화 90s)

궁극기 추적은 v0.1.0 제외, v2 재검토.

## 버튼
- 탭: 쿨다운 시작·취소.
- 롱프레스: 스펠 순환 (점멸→점화→회복→유체→탈진→방어→강타).

## 시각
4단계: 대기 / 카운트다운 / 임박(≤10s 깜빡) / 자동 복귀.

## 본체
- 손잡이 단일 탭 3단계: `−` → `≡` → `+` (펼침 / 라인 숨김 / 완전 접힘).
- 손잡이 드래그(touch slop 후) 이동.
- 크기 슬라이더 0.5x~1.5x.
- 포그라운드 서비스 + 알림.

## 입력 우선순위
화면 가림 + 수동 탭 정밀도 부족 → [auto-chat-detect](auto-chat-detect.md) 주력. 수동 탭은 폴백.
