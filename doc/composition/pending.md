# 조합 트랙 결정 보류

- **시너지 규칙 가중치** — 1차 모두 동등. 패치별 메타 가중치 동적 조정은 v2.
- **카운터 매트릭스 큐레이션 범위** — 현재 ~15명. 인기 챔피언 우선 50명까지 확장.
- **챔피언 검색 UX** — 현재 EditText filter. 즐겨찾기 / 최근 사용 v2.
- **결과 신뢰도 표기** — "제안일 뿐" UI 가이드 필요 (현재 미구현).
- **앱 챔피언 목록 캐시** — 현재 매 진입마다 fetch. SharedPreferences 캐시 추가 (Tier만 캐시됨).
- **로딩 화면에서 적 챔피언 자동 매핑** — `LoadingScreenParser` 인프라 박힘. 슬롯 자동 매핑 흐름은 v2.
