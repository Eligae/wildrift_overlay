# MVP 기능 범위

## 슬롯 구성
적 챔피언 슬롯 5개 (P1~P5). 각 슬롯에 버튼 3개:
- 스펠 1 (기본: 점멸 150s)
- 스펠 2 (기본: 점화 90s)
- 궁극기 (기본 60s)

## 버튼 동작
- **탭**: 쿨다운 시작. 재탭 시 취소.
- **롱프레스(스펠)**: 종류 순환 — 점멸 → 점화 → 회복 → 유체 → 탈진 → 방어 → 강타.
- **롱프레스(궁)**: 프리셋 순환 — 60 / 75 / 90 / 105 / 120s.

## 시각 상태 4단계
대기 / 카운트다운 / 임박(≤10s, 깜빡) / 완료(잠깐 강조 후 대기).

## 본체
- 좌측 손잡이(`≡`) 드래그로 이동, 더블탭으로 접기.
- 포그라운드 서비스 + 알림으로 백그라운드 유지.
