# Android 측 — 챔피언 메타 화면

인게임 트래커와 별개. 두 모드가 같은 데이터 공유.

## 두 모드
- **추천 카드** (밴픽용) — 라인 1개 + 상위 N명.
- **티어표** ([tier-table](tier-table.md)) — 전체 라인 한 표.

## 진입
- `MainActivity` "메타 보기" 버튼.
- 또는 오버레이 손잡이 트리플탭으로 모드 전환. 두 모드 간은 화면 상단 탭.

## 추천 카드 화면
1. 라인 선택 토글 (5개 라인).
2. 챔피언 카드 5개 — 아이콘 + 한글명 + 승률/픽률.
3. 새로고침 + 마지막 갱신 시각.

## 데이터
[server](server.md) `/v1/tier` 응답을 SharedPreferences 캐시. 두 모드가 동일 캐시 공유. 서버 장애 시 캐시 폴백.

## 오프라인 / 첫 실행
서버 미응답 + 캐시 없음 → "데이터 없음. 네트워크 확인".
