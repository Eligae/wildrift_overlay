# 10명 로딩 화면 — 적팀/우리팀 분리

## 사용자 인사이트
WR 매칭 순서:
1. 밴/픽 화면
2. **우리 팀 5명만** 보여주는 짧은 로딩 (= 우리 팀 anchor)
3. 양 팀 10명 로딩

10명 화면에서 챔피언 얼굴 좌→우 순서 = **TOP / JUG / MID / ADC / SUP** (사용자 확정).
한 row 5명 = 한 팀.

## 분리 전략
A. **두 단계 캡처 anchor**:
   - 2단계 (5명 화면) OCR → 5명 매칭 시 "우리 팀 후보" SharedPreferences 저장
   - 3단계 (10명 화면) OCR → 10명 중 우리 팀 5명 제외 → 적팀 확정
   - 슬롯에 적팀 broadcast

B. **단순 row 분리** (현재 시도):
   - y로 두 그룹 분리. 어느 쪽이 적팀인지는 캘리브레이션·검증 필요.

## 결정
A 안 채택. 2단계 anchor가 잡히지 못한 경우(타이밍 미스, OCR 부족) B 안 fallback.

## 검증 포인트
- 5명 화면 OCR 매칭 = 정확히 5명일 때만 anchor.
- 10명 화면에서 우리 팀 5명 제외 후 남은 챔피언이 5명이면 enemies로 확정.
- enemies < 5명이면 broadcast 안 함 (기존 임계값 가드 유지).

[[lane-order]]도 함께 정리 — 한 row 내 순서를 결정한 후 broadcast.
